# AuToFishing

โครงการพัฒนาต่อจากระบบเดิม โดยใช้ `ggezname/autofish` เป็นแหล่งอ้างอิงแบบอ่านอย่างเดียว **ไม่มีการแก้ไข repository เดิม** การพัฒนาทั้งหมดอยู่ใน `ggezname/AuToFishing-`

## เวอร์ชัน v0.4.0 — Restored UI + Core + ROI Guard

### ระบบเดิมที่นำกลับมา
- หน้าต่างลอย AutoFish v4.3 พร้อมปุ่มเริ่ม / หยุด / ตั้งจุด / ดีบัก / ปิด
- หน้าต่างดีบักและสแกนสด
- ตัวลากตั้งพิกัดจุดต่าง ๆ บนหน้าจอ
- ตั้งกรอบแถบตกปลาด้วยจุด +1 / +2 และแสดงกรอบจริง
- คาลิเบรตหน้าจอ 3 จุด รองรับการสเกลภาพจับหน้าจอ
- ตั้งโหมดถือเบ็ด, จำนวนรอบ, ระยะดักหน้า
- ระบบตกปลาอัตโนมัติและติดตามแถบขาว
- ระบบเปิดคลังและลากเก็บของ 4x4 ครบ 16 ช่อง โดยแสดงจุด 1–16 ตอนตั้งกรอบ
- ระบบหยุดงานและปิดม่านดำ

### ส่วนที่ปรับปรุงจากงานพัฒนาใหม่
- ใช้กรอบ `barStart/barEnd` ที่ผู้ใช้ลากกำหนดเป็น ROI จริงของระบบตรวจจับ
- ตรวจสอบว่ากรอบ ROI อยู่ภายในความละเอียดหน้าจอก่อนเริ่มทำงาน
- สแกนสีแดงหลาย scanlines (6 แนว) แล้วรวมผลที่ซ้อนทับกัน ลดการยอมรับจุดแดงเดี่ยว
- คำนวณ confidence จากจำนวนแนวสแกนที่ตรวจพบ
- จำกัดผลตรวจจับแถบแดงและตำแหน่งขาวให้อยู่ในกรอบ ROI ของผู้ใช้
- คงการติดตามตำแหน่งขาวและคาดการณ์เวลาจาก timestamp จริงของแต่ละเฟรม
- แยกไฟล์ต้นฉบับ `ui.js` และ `script.js`; `main.js` เป็นไฟล์รวมสำหรับ Loader

## วิธีติดตั้ง
1. เปิด AutoX.js และอนุญาตสิทธิ์แสดงหน้าต่างลอยกับจับภาพหน้าจอ
2. ใช้ Loader ที่ดาวน์โหลด `main.js` จาก GitHub branch `main` หรือเปิด `main.js` โดยตรง
3. เปิดเกมในหน้าตกปลา แล้วกด **ตั้งจุด**
4. ตั้งกรอบแถบตกปลาให้ครอบคลุมแนวแถบจริงอย่างพอดี จากนั้นใช้ **ดูกรอบแถบตกปลาจริง** ตรวจตำแหน่ง
5. ตั้งปุ่มตก, ปุ่มเปิดคลัง, กรอบกระเป๋า 4x4, จุดวางของ และปุ่มกลับเข้าเกม
6. เปิดดีบักและกดสแกนสดก่อน เพื่อยืนยันว่าแถบแดง/ขาวที่รายงานตรงกับภาพจริง
7. เมื่อยืนยันพิกัดและการตรวจจับแล้ว จึงกดเริ่มระบบจริง

## Loader
ใช้ URL:
`https://raw.githubusercontent.com/ggezname/AuToFishing-/main/main.js`

ตัวอย่าง Loader:
```javascript
"auto";
var URL = "https://raw.githubusercontent.com/ggezname/AuToFishing-/main/main.js";
try {
    toastLog("กำลังดาวน์โหลด AuToFishing...");
    var res = http.get(URL);
    if (!res || res.statusCode !== 200) throw new Error("HTTP " + (res ? res.statusCode : "ไม่มีการตอบกลับ"));
    var code = res.body.string();
    if (!code || code.length < 10000) throw new Error("ไฟล์ไม่สมบูรณ์");
    engines.execScript("AuToFishing", code);
} catch (e) {
    toastLog("AuToFishing Error: " + e);
    log(e);
}
```

## ข้อควรทดสอบก่อนใช้งานจริง
- ยังไม่ได้รัน AutoX.js บนอุปกรณ์ของผู้ใช้ จึงยังยืนยัน Redfinger / Samsung / OPPO / Xiaomi / BlueStacks / LDPlayer / MuMu ไม่ได้
- เริ่มจากดีบัก/สแกนสด ตรวจกรอบและตำแหน่งทุกจุดก่อน
- ทดสอบปุ่มตกและการเก็บของโดยเฝ้าดูหน้าจอ เพราะพิกัดและเวลาตอบสนองต่างกันตามอุปกรณ์
- การตรวจจับยังเป็นการวิเคราะห์สี (heuristic) อาจได้รับผลจากเอฟเฟกต์ แสง หรือธีมเกม
- ห้ามใช้พิกัดตัวอย่างจากอุปกรณ์อื่นโดยไม่ตั้งใหม่
- ระบบเก็บของจะลากทั้ง 16 ช่องตามลำดับแถวซ้ายไปขวา; ตรวจให้จุดทั้ง 16 อยู่กึ่งกลางช่องก่อนเริ่ม
- หากพบการกดพลาด ให้หยุดทันทีและปรับกรอบ ROI / คาลิเบรตก่อนทดสอบรอบใหม่

## ไฟล์
- `main.js` — ไฟล์รวมสำหรับ Loader
- `ui.js` — UI และการตั้งค่าจากระบบเดิม
- `script.js` — core, detector, calibration, fishing และ vault automation
